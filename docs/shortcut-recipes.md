# 快捷指令配方

目标：**轻点背面两下 → 截屏 → 识别 → 自动入账**，全程不切 App、不存图片。

App 提供了两个动作（在快捷指令 App 里属于「小满」）：

| 动作 | 输入 | 用来干嘛 |
| --- | --- | --- |
| **小满记账** | 图像 / 文件 | 识别截图里的账单，自动入账或进待确认 |
| **文本记账** | 文本 | 把一段账单文字（剪贴板、其他 App）解析成账目 |

前提：App 至少打开过一次（这样动作才会被系统登记，URL Scheme 才生效）。

---

## 配方 A：双击背面 → 截屏 → 记账（推荐）

| 步骤 | 操作 |
| --- | --- |
| 1 | 打开「快捷指令」→ 右上角 **+** 新建 |
| 2 | 搜索 **截屏**（Screenshot），添加。它会产出一张截图 |
| 3 | 搜索 **小满记账**，添加。这个动作有个「截图」输入框，点进去选 **截屏** 这一步的结果（快捷指令会自动接上；没接上就手动选「截屏」） |
| 4 | 给快捷指令改个名字，比如 `双击记账`，存到「我的快捷指令」 |
| 5 | 设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下 → 选中 `双击记账` |

之后在任何支付成功页，双击手机背面：

- 识别把握度 ≥ 0.8 且不是重复记录 → 直接入账，快捷指令顶部弹一句「已记账 ¥28.50 · 星巴克咖啡，记在「微信钱包」」
- 否则 → 弹「已识别…等你确认」，打开 App 就能看到待确认列表

> 如果每次都要你手动点一下才运行，进快捷指令详情页把「运行前询问」关掉。

### 常见变体

- **想看到结果**：在「小满记账」后面加一个「显示结果」。
- **手动触发**：把快捷指令放到主屏图标、锁屏按钮、控制中心，一样能用。
- **只想识别不想入账**：到 App「设置 → 记账」里关掉「高把握度自动记账」，所有识别结果都会进确认页。

## 配方 B：文本通道（备用）

有些场景拿不到图像，只能拿到文字（别的 App 复制出来的账单、网页账单）。这时用文本动作或 URL 深链接。

### B1：文本动作

| 步骤 | 操作 |
| --- | --- |
| 1 | 新建快捷指令，加 **文本**，把账单文字粘进去 |
| 2 | 加 **文本记账**，输入选上一步的文本 |
| 3 | 绑定到轻点背面或主屏图标 |

### B2：URL 深链接

模板（复制到快捷指令的「文本」里，后面接变量）：

```
xiaoman://record?text=
```

支持的参数：

| 参数 | 别名 | 说明 |
| --- | --- | --- |
| `text` | `t` / `content` / `ocr` | 账单全文（必须做 URL 编码） |
| `src` | `source` | `wechat` / `alipay` / `unionpay` / `meituan` / `jd` / `bank` |
| `amount` | `amt` / `a` | 直接指定金额，覆盖识别结果 |
| `merchant` | `m` / `shop` / `payee` | 直接指定商户 |
| `cat` | `category` | 直接指定分类名 |
| `ts` | `time` | 时间戳（秒或毫秒）或 `2026-11-18 10:22:31` |
| `note` | `remark` | 备注 |

例：

```
xiaoman://record?text=%E5%BE%AE%E4%BF%A1%E6%94%AF%E4%BB%98%20-%C2%A528.50&src=wechat&amount=28.50
```

App 内「设置 → 记账 → 粘贴文本识别一笔」可以手动贴一段账单文字，确认解析链路是通的。

> URL 长度有限（账单页文字一多会被截断），所以优先用配方 A。

## 排错表

| 现象 | 原因 / 处理 |
| --- | --- |
| 快捷指令里搜不到「小满记账」 | 装完 App 后先**打开一次**；仍没有就重启「快捷指令」App，并确认 iOS ≥ 26 |
| 动作显示「需要输入」 | 第 3 步的输入没接上，点输入框选「截屏」的结果 |
| 双击背面没反应 | 设置 → 辅助功能 → 触控 → 轻点背面 里确认选的是这个快捷指令；手机壳太厚也会失灵 |
| 提示「没能确认金额」 | 截图里没有可识别的金额，或支付页还没渲染完；进 App 的待确认列表手填 |
| 每次都进确认页 | 把握度低于 0.8（截图里缺商户或时间），或关掉了自动记账；「设置 → 记账」里可以打开 |
| 资产记错了 | 识别靠关键词（「微信」「支付宝」「储蓄卡」等）；到「资产」页给对应资产补关键词，或在确认页手选 |
| 重复记了两笔 | 同来源 + 同金额 + 同商户 + 同一分钟会判重复并进确认页；真重复了就在账单里左滑删除 |
| 通知不响 | 设置 → 通知 → 小满 → 允许通知；App 内「预算」页也会提示去系统设置 |
| 预算不显示 | 先在「预算」页顶部输入月预算并保存，首页才会出现今日额度 |

## 验收清单

1. 手动点一次快捷指令的「运行」，顶部出现一句识别结果。
2. 打开 App，首页「最近记录」多了一条，金额、分类对得上。
3. 双击背面两下，在微信/支付宝的支付成功页试一次，几秒内出现提示。
4. 「预算」页设好月预算，首页出现今日额度环；花超了变红。
