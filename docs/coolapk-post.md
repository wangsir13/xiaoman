## 二、正文（直接复制，纯文本）

【一句话】
双击手机背面截图，账就自己记好了——不用打开 App，不用连银行。

做这个 App 的原因很土：我每个月都知道自己花了钱，但从来不知道自己花在哪。微信、支付宝、银行卡三个地方各记各的，月末对不上账；下过几个记账 App，最后都死在「要手动输入」这一步。

小满只解决这一件事：把「记账」这个动作从你身上拿走。

【怎么用】
① 快捷指令里新建一个：加「截屏」→ 加「小满记账」动作（输入选「截屏」的结果）
② 设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下 → 选这个快捷指令
③ 以后付款完，双击背面，截图直接交给小满识别，自动入账

重点：截图**不落地、不留相册**，系统把图像直接交给 App，本地 OCR 认完就完事。你相册里不会多出一堆账单截图。

【认得出什么】
· 微信支付、支付宝、云闪付、美团、京东、银行短信
· 金额、商户、时间、收/支方向
· 金额优先认「实付款 / 支付金额 / 交易金额」这类带标签的，再退到单独一行的数字，千分位和全角数字都吃
· 商户会过滤掉「支付成功」「订单号」「尾号」这些噪声，认得「来自 张三」「收款方」这种格式
· 把握度低的单子不会自动入账，会进「待确认」让你扫一眼

【钱花在哪，一眼能看到】
· 首页是健康 App 那种信息密度：本月支出大数字 + 今日预算环 + 分类环 + 资产
· 资产：银行卡、信用卡、微信/支付宝钱包、借款，支出自动从对应资产扣，识别不出可以手动绑
· 预算：月预算按天均分，今天花超了从明天额度里扣；花不完自动攒到明天
· 还有一个「清空今日前预算」按钮：第一次用、不想把上半个月补记进来的时候，点一下从今天开始算
· 房租、话费这类固定支出可以标记成「固定支出」，照常记账但不占每日额度
· 账单页有分类饼图、每日柱状图；还有一整年的记账热力图和月度长图（可以直接发朋友圈）

【关于数据】
· 纯本地：JSON 存在 App 沙盒里，没有账号、没有云同步、没有广告
· 默认完全不联网。只有你自己在设置里打开「AI 复核」并填了 API Key，才会把**账单文字**发给你选的那家模型（DeepSeek / GPT / Claude / 豆包 / 自定义接口），不发图片
· 可以导出 CSV（带 BOM，Excel 不乱码）、也能导出/恢复整份 JSON 备份
· 支持导入微信、支付宝导出的 CSV / xlsx / zip 账单，会自动去重

【界面】
iOS 26 的液态玻璃（Liquid Glass）做的，深浅色都适配，可以开 Face ID 锁。

【怎么装】
这是个人自签的 App，不在 App Store，需要自己签：
① 仓库 Actions 里下载未签名 ipa
② 用 AltStore / SideStore 签名安装（免费证书 7 天要续一次，AltStore 会自动续），或者 TrollStore 直接装
③ 要求 iOS 26 及以上

【已知问题】
· 免费证书 7 天有效期，忘了续签会打不开（数据还在，续签覆盖安装即可）
· 小部件没做：需要 App Group 权限，免费自签拿不到，所以先用「查今日额度」快捷指令动作替代
· 识别不可能 100%，模糊的单子会进待确认，请扫一眼再存

## 七、精简版（直接发这个）

标题：截图即入账｜小满 · 本地记账

正文：

双击手机背面完成截图，账单随即入账，无需打开应用。

记账的难点从来不在「记」，而在「输入」。小满将这一步交给系统：截图由快捷指令直接传入应用，在本地完成文字识别与结构化，截图不留存在相册。

配置方式共三步：
一、在快捷指令中新建流程，依次添加「截屏」与「小满记账」，将后者输入指定为截屏结果；
二、进入设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下，选用该快捷指令；
三、付款完成后双击背面即可完成记账。

识别覆盖微信、支付宝、云闪付、美团、京东及银行短信，提取金额、商户、时间与收支方向；置信度不足的记录进入待确认列表，由使用者核对后入库。

界面按信息层级组织：本月支出、今日预算环、分类构成、资产余额。预算按日分配，当日超支由次日额度承担；房租、话费等可标记为固定支出，不占用每日额度。另提供分类饼图、年度记账热力图与月度结算长图。

数据仅存储于本机，无账号体系，默认不联网。仅在启用 AI 复核并填写密钥后，账单文本才会发送至所选模型服务商，图像不会上传。支持导出 CSV 与整份 JSON 备份。

版本要求 iOS 26 及以上，以自签方式安装（AltStore 或 SideStore，证书有效期为七天）。应用免费，无内购。

使用中的问题与建议，可在评论区提出。
